# Getting help

- **Using the platform** — the [help center](https://cdp.onetrace.pro/docs/en) has step-by-step articles with screenshots for every section; the [API reference](https://onetrace.pro/en/docs/api) covers the public API and the tracker.
- **Your account, billing or a problem with your project** — email [support@onetrace.pro](mailto:support@onetrace.pro). Please do not post project data or API keys in public issues.
- **A bug or an idea for a library or plugin** — open an issue in its repository.
- **A security issue** — follow the [security policy](SECURITY.md), not public issues.
- **A walkthrough on your use case** — [book a demo](https://onetrace.pro/en/demo).
